# MiniDampen

Small arena and solo shuffle readout: a team alive-count, the dampening
percentage, and your solo shuffle round record.

One draggable frame, either showing numbers or shape-coded pips for
colourblind readability. That's it.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
